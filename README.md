# RSR Technologies — React Website

A responsive, modern multi-section corporate website starter for RSR Technologies built with React, Vite and Lucide icons.

## Features
- Responsive fixed sidebar navigation and sticky header
- Home, About, Services, Application Showcase, Training & Careers, Promotions, Partners & Industries, Contact sections
- Custom SVG-style RSR logo treatment in the interface
- Service portfolio across AI Fullstack, data, web/mobile, AI chatbots/agents, robotics, marketing, BPO, support, training and placements
- Application showcase including KYP, CLP, Buildwise, Edunovae, LMS, property/community apps, social analytics and others
- Founder & CEO Ramesh S P; COO & HR Head Sunita Ramesh
- Industries served, partnership callouts, promotional content and clearly marked testimonial placeholders
- Contact form interaction (frontend demo only)
- Image-rich responsive UI, gradient accents and social link placeholders

## Run locally

```bash
npm install
npm run dev
```

For production build:

```bash
npm run build
npm run preview
```

## Before publishing
1. Add verified company email and phone number in the Contact section.
2. Replace generic social media URLs with RSR Technologies' official profiles.
3. Connect contact form to a backend/API or CRM (the current form is client-side demo only).
4. Replace illustrative testimonial placeholders with approved customer/student/partner testimonials.
5. Add only authorized customer/partner logos and confirmed references. Portfolio entries are framed as work, initiatives or concepts; confirm status and scope before claiming delivery publicly.
6. Replace external Unsplash images with licensed company-owned images if desired.
7. Configure SEO metadata, analytics, cookie/privacy policies and deployment domain.

## Stack
React, Vite, CSS, Lucide React icons.
